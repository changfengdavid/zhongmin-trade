# 青岛中旻门户 · 外网访问与静态域名设置

本系统已部署在 **G:\\ZhongMinWebsite**，数据（公司信息、产品、图片）全部保存在本机 G 盘，不上云。

官网域名：**zhongmin-trade.com**

> 🚀 **最短路径（现在就用，免买域名）**：先双击 `启动网站.bat`，再双击 `临时外网.bat`，
> 屏幕会显示 `https://xxxx.trycloudflared.com`，复制发给客户即可外网访问。
> 等买了 `zhongmin-trade.com` 之后，双击 `配置固定域名.bat` 绑定一次，以后 `外网访问.bat` 自动改用固定域名。

## 一、本机访问
1. 双击 `启动网站.bat`（或 `server.bat`），保持窗口开着。
2. 浏览器打开：
   - 官网首页：http://localhost:8080/
   - 后台管理：http://localhost:8080/admin/  （默认密码 `admin123`，请尽快修改）

---

## 二、外网访问（两种方式）

### 方式 1：临时外网地址（免账号，立即可用）
适合临时发给客户看效果。
1. 先确保 `启动网站.bat` 已运行（本机 8080 在跑）。
2. 双击 **`临时外网.bat`**（或直接用 `外网访问.bat`，两者等价，临时模式下都走免登录隧道）：
   - 首次会自动下载隧道工具 cloudflared（约 30MB，失败可手动下，见脚本内链接）。
   - 屏幕显示 `https://xxxx.trycloudflared.com` 地址，发给客户即可外网访问。
3. **注意**：这是临时地址，每次重连会变。要固定域名看方式 2。

> 原理：Cloudflare Tunnel 由本机主动向外发起连接，因此**不需要公网 IP、不需要路由器端口映射**，也不受家庭宽带无公网 IP 的限制。

### 方式 2：固定域名 zhongmin-trade.com（推荐，免费）
让网站长期、永久地在 **https://www.zhongmin-trade.com** 对外可访问。

**一次性准备（双击 `配置固定域名.bat` 自动引导）：**
1. 域名 `zhongmin-trade.com` 需在 [Cloudflare](https://www.cloudflare.com) 免费接入（添加站点、按提示修改 NS）。
2. 双击 `配置固定域名.bat`：
   - 自动下载 cloudflared；
   - 打开浏览器让你登录 Cloudflare（免费账号），选择该域名；
   - 自动创建命名隧道 `zhongmin` 并把 `www.zhongmin-trade.com` 与 `zhongmin-trade.com` 指向它；
   - 记录隧道名到 `bin\.tunnel_name`。
3. 之后双击 `外网访问.bat` 即走固定域名模式，地址**永久不变、HTTPS 加密**。

## 三、开机自启 / 7×24 常驻
双击 `开机自启.bat`（建议右键“以管理员身份运行”）：
- 创建 Windows 计划任务 `ZhongMinPortal`（当前用户登录时自动运行）。
- 自动启动 `启动全部.bat` → 同时拉起官网服务 + 外网隧道（使用 `外网_自动.bat`，自带日志）。
- 电脑重启后无需手动操作即自动上线。
- **重启后临时地址会变**：当前对外地址记录在 `G:\ZhongMinWebsite\临时地址.log`（固定域名模式则在 `外网日志.log`）。绑定固定域名后地址不变，见“方式 2”。

> 说明：`onlogon` 模式在“该用户登录后”自动启动（覆盖 99% 场景）。若需“无人登录也常驻”，可把任务改为“不管用户是否登录都要运行”（任务计划程序 → ZhongMinPortal → 属性 → 安全选项），但因服务以 SYSTEM 运行需另行配置 node 路径，普通场景用默认即可。

## 四、注意事项
- **保持运行**：外网可访问依赖 `启动网站.bat`（本机 8080）一直运行。用 `开机自启.bat` 最省心。
- **防火墙**：用 Cloudflare 隧道**不需要**在防火墙放行 8080（隧道是出站连接）。
- **改端口**：如需改端口，同步修改 `server.bat`、`启动网站.bat`、`外网访问.bat` 里的 `PORT`。
- **数据安全**：所有编辑写回 `G:\ZhongMinWebsite\data\config.json` 与 `public\uploads\`，建议定期备份这两个目录。
- **待替换真实信息**：config 中电话、地址、微信、合作伙伴、资质图片等为占位，请在后台 `admin` 替换为真实资料。

## 七、云端发布（免域名、外网可访问）

> **重要澄清**：「设置 → 数据管理 → 我发布的应用」只是**查看/下线**已发布应用的地方，**没有发布按钮**；WorkBuddy 的"发布为应用"是由 AI 在对话里调用内置工具执行的，且**当前这个会话没有挂载该工具**，无法直接帮你推上云。
>
> 因此对外网访问请用下面**确定能用**的第三方免费云方案（详见 **`云端部署指南.md`**）：

1. **方案 A · Render**（推荐，免费，固定 `xxx.onrender.com`）：连 GitHub 仓库部署，最稳。
2. **方案 B · Koyeb**（免 Git 需装 CLI，或走 GitHub）：固定 `xxx.koyeb.app`（详见 `云端部署指南.md`）。
3. **方案 C · 轻量云服务器**（约 ¥60/年起，国内最快最稳）：腾讯云/阿里云。
4. 也可继续用已有的 **Cloudflared 临时隧道**（本机常开，地址每次变）。

**核心原则：G 盘是源，云端是镜像 —— 本地 `admin` 改完务必“重新部署”一次，客户看到的才会更新。**

- 本地维护：`http://localhost:8080/admin/` 改内容、传图。
- 双击 **`发布前检查.bat`** 自检（绿灯即可）。
- 同步代码到云平台并点 Deploy/Redeploy。
